The placement of each species within the three functional clusters is indicated, and ordination values are given The life-history traits are (1) migration, where each species is classified as either migratory or non-migratory; (2) body size, indicated as the average forewing length of both males and females (mm); (3) host plant specialization, where each species is classified as either ‘monophagous’ (only using one host plant), ‘oligophagous’ (using several host plants from the same genus) or ‘polyphagous’ (using many different host plants); (4) host plant distribution, classified as either ‘widespread’ or ‘local’. If a butterfly species is oligo- or polyphagous, only the distribution of the most widespread host plant is shown; (5) habitat selection, where species are classified as either ‘specialists’ (using only one habitat type), ‘semi-specialists’ (using two different habitat types) or ‘generalists’ (using  three or more different habitat types); (6) habitat openness score, with regards to vegetation, where 1=completely open (e.g. grassland or heath), 2=semi-open and 3=completely closed (i.e. forest). If a species uses several different types of habitat the average openness score is indicated; (7) overwintering strategy,  i.e. egg, larvae, pupae or adult (8) Voltinity, ie. each butterfly species’ number of generations per year.
