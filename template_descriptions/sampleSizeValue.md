Definition: A numeric value for a measurement of the size (time duration, length, area, or volume) of a sample in a sampling

Notes:
- Extract the number directly. If reported as a range or with comparators (>50, ~100), keep the original form.
- For percentages, include the % sign.
- If sample size is implicit (e.g., a single measurement), use 1.
- If not reported, return null.

Examples: 	5 (sampleSizeValue) with metre (sampleSizeUnit)
