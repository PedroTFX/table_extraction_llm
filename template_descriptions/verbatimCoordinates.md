Describe the `verbatimCoordinates` tag here.

Definition: The coordinate string as presented in the source (free-text), e.g., degrees/minutes/seconds or decimal formats.

Examples:
- "34°12'34"S 118°15'22"W"
- "-34.2094, 118.2561"

Guidance: Preserve the source formatting; if extracting numeric lat/long, store in separate normalized fields.
