Definition: Categorization of individuals for eusocial species (e.g., termites, ants, bees, wasps).

Valid values (common):
- queen
- king (termites)
- worker
- minor worker / major worker
- soldier
- alate / male alate / female alate (winged reproductives)
- nymph (immature castes)

Notes:
- Use this for eusocial insects only — for non-social species, return null.
- Soldier and worker are CASTES, not life stages or sexes.
- If the paper studies a specific caste (e.g., "soldiers were collected"), use that.
- If the paper pools data across castes, use null or "all".

Examples: queen, worker, soldier, male alate, minor worker
